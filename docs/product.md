# 产品

## 1. 问题

Herdr 把多个 coding agent 组织成 workspace / tab / pane，跑在开发者的机器上。它解决「同时开很多 agent」，没解决「人离开键盘之后」：

- agent 卡在审批上，整条流水线空等；
- 想知道有没有事，得连 SSH、进 Herdr、逐个 pane 看；
- 通用 SSH 客户端能连上，但 6 寸屏上的终端只是「电视」，不是遥控器。

**Herdly 只做三件事：看场、决断、交代。** 长内容、复杂编辑、代码审查回桌面。

## 2. 用户与场景

| 用户 | 场景 | 成功标准 |
| --- | --- | --- |
| 同时开多个 agent 的个人开发者 | 离开工位、通勤、会议间隙 | 打开 App 能找到等待中的任务并处理 |
| 管多台机器的人 | 家里 / 公司等多台机器上的 Herdr | 不用记哪台机器，收件箱直接给结论 |
| 怕误操作的人 | 删除、写文件、提权、装依赖 | 展示原始上下文，发送前复核，明确提示不确定结果 |

核心任务：**发现等待 → 读懂上下文 → 安全地回一句 → 核对结果**。请求已接受、屏幕变化和任务成功分别表达。

## 3. 边界

做：连接、观察、决策、短指令、轻量派活。

不做：系统通知 / 角标、后台常驻、自动批准、云端中继、代码编辑、完整 VT 终端、批量审批、本地回执、通用 LLM 聊天、agent 编排。

## 4. 信息架构

```text
收件箱（默认）
  ├─ 筛选：全部 / 只看需要我
  ├─ 搜索：名称、仓库、机器、类型、工作区 / 标签页、pane ID、cwd
  └─ Agent 详情
       ├─ 当前决定 / 操作结果
       ├─ 屏幕证据 + 读取更多
       ├─ 固定回复框 / 可展开终端按键
       ├─ 状态来源（agent.explain）
       └─ ⋮ 重命名 / 中断
机器
  ├─ 主机状态、重连、编辑、删除
  └─ 结构（该主机）
       ├─ 工作区
       │    └─ 标签页
       │         └─ 分屏（agent / shell）
       ├─ 新建任务
       ├─ 新建工作区 / 标签页
       ├─ 启动 agent / 按原 pane 恢复
       └─ 重命名 / 分屏 / 关闭 / 聚焦
设置
  ├─ 刷新与生命周期
  ├─ 凭据、主机指纹、数据边界
  └─ 主机要求与协议
```

底部只有三个入口：**收件箱 / 机器 / 设置**。结构属于「机器」，不是第四个 tab。

## 5. 收件箱

### 5.1 分区与排序

| 分区 | 来源 | 排序 |
| --- | --- | --- |
| 等你 | `blocked` | 等待最久优先 |
| 未识别 | `unknown` | 变更序号倒序 |
| 待查看 | `done` | 变更序号倒序 |
| 进行中 | `working` | 变更序号倒序 |
| 空闲 | `idle` | 变更序号倒序 |

- **每个 agent 单独一行，不合并空闲**。每行的等待时长由客户端按「同一状态持续多久」计算。
- 没有人在等时，顶部只留一句冷静的摘要，不放大红色警报。
- 「只看需要我」= 等你 + 未识别 + 待查看。
- 待查看只反映 Herdr 的 `done`；客户端没有「标记已读」API，也不假装有。

### 5.2 行内容

- 第一行：状态形状 + 名称；等待任务有左侧强调线。
- 第二行展示机器 / 工作区，第三行补充标签页、pane 与类型；状态与等待时长独立一行，避免大字体时挤压任务名称。
- 页首摘要合并等待数量、最久等待与查看入口；机器标签可直接打开对应机器。没有搜索结果时提供清除搜索 / 重置筛选。
- 点整行进详情；详情导航条支持上一条 / 下一条及横滑，按打开时的筛选队列遍历。收件箱支持下拉刷新。
- 断线保留上次快照，明确显示离线和成功同步时间，避免旧数据看起来仍是实时状态。

### 5.3 空态

- 无主机：「添加第一台机器」+ 可复制的 `herdr remote-api-bridge --check`。
- 有主机、无 agent：说明 agent 还没启动，给「新建任务」入口。
- 全部安静：不编造通知，不承诺推送。

## 6. Agent 详情与审批

### 6.1 屏幕

- 深色等宽证据区，默认软换行，可切换横向阅读；原文默认完整保留。
- 顶部显示读取时间；`读取更多` 向 Herdr 请求更多行。可选聚焦模式仅折叠装饰和多余空行，复制与审批始终使用原始证据。
- 向上滚动只停止自动跟随，3 秒自动读取仍继续；有新内容时显示回到底部入口，回到底部恢复跟随。
- `选择复制` 打开可选择文本的弹层，支持全选与复制选中。
- `全屏`、审批卡的 `核对屏幕原文` 或更多菜单进入冻结的原文阅读器；提供不区分大小写的查找、高亮、匹配行循环跳转、11–20sp 字号与换行切换，复制始终使用原文。关闭后按原有暂停设置恢复更新。
- 屏幕内容可能被截断，必须显示截断提示，不伪造 scrollback。

### 6.2 审批卡

解析器只处理两类高置信界面：

1. 编号菜单：至少两个连续编号选项，且有问句/操作上下文；
2. y/n 或 Enter/Esc 确认。

解析不出时不猜，显示「这个屏幕我没敢猜」，保留按键与回复框。

按钮语义：

- 所有选项完整显示原始文案，包括多个授权范围；发送前重读屏幕。
- 「总是允许 / 本会话允许」：属于长期授权，必须二次确认。
- 风险标签只做提示，不代替人判断。

### 6.3 发送前复核

1. agent 必须仍在等你或未识别；
2. 重新读屏幕；
3. 问题、全部选项、按键序列及完整上下文一致，证据截断时不提供辅助审批；
4. revision 可用且变化时拒绝；revision 为 0 时仍比较完整证据；
5. 请求返回后再读屏幕，分别说明请求接受与屏幕变化。没有变化或读取失败时不宣称没送到，也不自动重发。

复核失败不发，并说明原因。同一审批证据已提交后限制重复操作；不确定的写入需要刷新、阅读并显式核对后解除限制。**请求接受和屏幕变化均不证明任务成功。**

回复草稿按 agent 保留，切页、旋转和后台返回不丢失；仅在接受后清理同一版本草稿。键盘弹出时回复区保持可见，终端按键默认折叠，中断独立确认。进程死亡后的草稿恢复尚未提供。

读屏与发送之间仍有竞争窗口，完全消除需要 Herdr 提供原子条件写入 API。

## 7. 结构与任务

- 结构页按 Herdr 的真实层级展示；不把桌面布局缩成手机上的迷你地图。
- agent pane 始终显示；空 shell 默认折叠，可展开，避免十几行噪音。
- 新建任务一次完成：选在线机器 → 新工作区或已有工作区 → agent 类型 / 名字 / 续接参数 → 启动。
- 启动 / 恢复到已有 pane 时只提供可保守确认的空 shell，排除当前占用；额外参数每行一个，保留空格。
- 恢复：记住每个 pane 上次的 agent；Herdr 或 App 重启后，可向原 pane 重新启动并续接会话。
- 关闭工作区 / 标签页 / 分屏必须确认；不做批量关闭。
- 重命名覆盖 workspace / tab / pane / agent，让多窗口可辨认。
- worktree 只展示 Herdr 已有信息；暂不支持在手机上创建工作树。

## 8. 视觉语言

- **一个主色，四种状态色，其余是墨色与留白**；状态色每行最多出现一次。
- 形状表达状态：等你=实心点 + 左轨；进行中=3/4 环；待查看=对勾环；空闲=空环；未识别=虚线环。
- 状态文案：等你 / 进行中 / 待查看 / 空闲 / 未识别。
- 图标：米白机器人 + 墨色面罩，一只米白眼睛、一只橙眼，橙色天线点——「一个 agent 需要你」。
- 字体：跟随系统的无衬线字体（Compose `SansSerif`），不内嵌字体；命令、路径、id 用等宽。
- 间距 4/8/12/16/20/24/32；行分隔用发丝线，不用卡片套卡片。
- 动效用于方向与状态：详情进入 / 返回方向相反，主入口淡入淡出，列表按稳定 key 迁移，切换任务拖动有反馈；筛选颜色 / 下划线、底部入口选中、搜索与错误详情展开提供轻量过渡；仅工作状态旋转。系统关闭动画时遵循 Compose 的动画时长缩放。

## 9. 文案原则

- 说结果，不说实现：「前台 5 秒一次，离开即断开」，不写「基于轮询」。
- 失败必须给下一步：「主机指纹变了，可能是重装，也可能是有人在中间」+ 查看差异 / 信任新指纹。
- 不承诺没做到的事：没有通知就写没有通知；没有回执就不写回执。
- 危险动作的确认按钮写动词，不写「确定」。
