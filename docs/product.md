# 产品

本文是**范围、页面职责与验收标准**的唯一权威。视觉与交互细节见 `docs/design/style-direction.md`，协议与实现见 `docs/engineering.md`。

## 1. 定位

**一句话**：手机上一台可信、好用的 SSH 终端，并且能读懂你的 AI agent 现在需要什么。

两层能力，顺序不能反：

- **L1 SSH 客户端**（地基）：主机管理、密码 / 私钥认证、交互式终端、按键栏、输入法、复制粘贴、断线后保留快照并原地重连。
- **L2 Herdr 值守**（增值）：连上主机里的 Herdr 桥，把「哪个 agent 在等我、它问什么、我能怎么答」变成一次点击。

上一版的失误记录在案：把一个 SSH 客户端做成了「Herdr 监控仪表盘」——终端是附属品、信息密度过高、界面像模板。

**不做**：系统通知 / 角标、后台常驻与前台服务、自动批准、云端中继、遥测、代码编辑、批量审批、多主机批量执行、agent 编排、通用 LLM 聊天。

## 2. 场景与成功标准

| 场景 | 诉求 | 产品回答 | 验收 |
|---|---|---|---|
| 通勤路上想起一个任务 | 看它卡在哪 | 打开即见值守收件箱 | 3 秒内说清「谁在等、等多久」 |
| 临时敲几条命令 | 立刻能用 | 机器卡片 → 打开终端 | 2 次点击进入可输入状态 |
| agent 要授权 | 判断风险再回复 | 证据原文 + 选项原文 + 风险标注 | 所有选项 1 次滚动内可见且不截断 |
| 长任务跑着 | 不丢上下文 | 断线保留上次快照，回来先显示再刷新 | 离线状态与最后同步时间必须可见 |
| 换一台机器 | 不迷路 | 机器列表带在线状态；终端顶部常驻主机身份 | 一眼看出哪台在线 |

核心任务链：**发现等待 → 读懂上下文 → 安全地回一句 → 核对结果**。请求已接受、屏幕变化、任务成功是三件事，分别表达。

## 3. 信息架构

```text
底部三个入口
├─ 值守 Inbox（默认）
│    ├─ 筛选：全部 Agent / 需要处理；多主机时出现机器标签
│    ├─ 搜索：名称、仓库、机器、类型、工作区 / 标签页、pane ID、cwd
│    └─ Agent 详情
│         ├─ 一行状态条（错误 > 操作结果 > 陈旧 > 读取时间）
│         ├─ 终端快照 + 全屏阅读器
│         ├─ 固定回复框 / 可展开终端按键
│         ├─ 审批面板（底部弹层）
│         └─ ⋮ 重命名 / 中断 / 状态来源 / 快照行数
├─ 机器 Hosts
│    ├─ 打开终端（主路径）→ 终端页：真实 SSH 会话
│    ├─ 连接会话（Herdr 桥）/ 连接详情 / 编辑 / 移除
│    └─ 结构
│         ├─ 工作区 → 标签页 → 分屏（agent / shell）
│         ├─ 新建任务 / 新建工作区 / 新建标签页
│         └─ 启动 agent / 按原 pane 恢复 / 重命名 / 关闭 / 聚焦
└─ 设置 Settings
     ├─ 外观（语言 / 主题 / 动效 / 密度）
     ├─ 终端（字号 / 默认快照行数 / 按键栏 / 长按连发 / 输入模式）
     ├─ 本机安全（重置主机指纹）
     └─ 关于与诊断（版本 + 检查更新）
```

底部只有三个入口；结构属于「机器」，不是第四个 tab。设计系统样式页从**长按设置页标题**进入，不占设置行。

**导航规则**：任何页面返回都回到来处；详情进入用反向位移、返回同向；终端页从机器列表进入就回机器列表。

## 4. 值守收件箱

职责：回答「现在谁需要我」，不承担连接管理。

| 分区 | 来源 | 排序 |
| --- | --- | --- |
| 等你 | `blocked` | 等待最久优先 |
| 未识别 | `unknown` | 变更序号倒序 |
| 待查看 | `done` | 变更序号倒序 |
| 进行中 | `working` | 变更序号倒序 |
| 空闲 | `idle` | 变更序号倒序 |

- 每个 agent 单独一行，不合并空闲；等待时长按「同一状态持续多久」由客户端计算。排序实现见 `docs/engineering.md`。
- 「需要处理」= 等你 + 未识别 + 待查看。待查看只反映 Herdr 的 `done`；没有「标记已读」API，也不假装有。
- 页首单行摘要合并等待数、最久等待与查看入口；没有人在等时只留一句冷静摘要，不放大红色警报。
- 行内容：状态形状 + 名称 + 等待时长 / 状态；第二行是 pane、工作区 / 项目，未筛选机器时追加机器名。
- 机器标签筛选当前队列，详情前后导航沿用此范围；无搜索结果时给清除搜索 / 重置筛选。
- 点整行进详情；详情支持上一条 / 下一条与横滑；收件箱支持下拉刷新。
- 断线保留上次快照，明确显示离线与最后成功同步时间。
- 空态给下一步：无主机 →「添加第一台机器」+ 可复制的 `herdr remote-api-bridge --check`；有主机无 agent →「新建任务」；全部安静 → 不编造通知。

验收：100 个 agent 滚动不掉帧；空态永远给出下一步。

## 5. Agent 详情与审批

职责：让用户在**不误操作**的前提下做一个决定。

### 5.1 屏幕

- 深色等宽终端占据剩余阅读空间，默认软换行，可切横向阅读；回复框与审批入口固定在底座，不占终端滚动区。
- 状态只占一行：错误 > 操作结果（含不确定）> 陈旧 > 读取时间，取一条消息 + 一个动作。终端高度不随状态变化。
- 默认请求最近 400 行，可扩到 1200 行并恢复默认；范围按 agent 在本次应用会话内记忆。这是**请求范围**，不保证远端返回同样行数；协议没有历史游标，不能翻页取更早 scrollback。
- 向上滚动只停止自动跟随，3 秒自动读取继续；有新内容显示回到底部入口。
- 聚焦模式仅折叠装饰与多余空行；复制与审批始终使用原始证据。
- `选择复制` 打开可选择文本弹层；`全屏` / `核对屏幕原文` 进入冻结的原文阅读器，支持不区分大小写查找、高亮、匹配行循环、11–20sp 字号与换行切换。关闭后按原暂停设置恢复更新。
- 内容被截断必须显示截断提示，不伪造 scrollback。

### 5.2 审批面板

解析器只处理两类高置信界面：编号菜单（至少两个连续编号 + 问句 / 操作上下文）、y/n 或 Enter/Esc 确认。解析不出时不猜，显示「这个屏幕我没敢猜」，保留按键与回复框。

- 底座固定显示问题摘要 +「查看选项」；完整问题、风险提示与**全部**原始选项在可滚动底部面板中展示，含多个授权范围。
- 打开面板时暂停自动更新；校验拒绝时保留面板与原因；操作开始后返回终端显示结果。发送前仍重读屏幕——暂停更新不等于远端冻结。
- 「总是允许 / 本会话允许」属长期授权，必须二次确认。风险标签只提示，不代替人判断。

### 5.3 发送前复核

规范性条件清单在 `docs/engineering.md`「审批和发送」，此处只定语义：复核失败不发并说明原因；同一审批证据提交后限制重复操作；不确定的写入需要刷新、阅读并显式核对后解除限制。

**请求接受和屏幕变化都不证明任务成功。** 读屏与发送之间仍有竞争窗口，完全消除需要 Herdr 提供原子条件写入 API。

回复草稿按 agent 保留，切页、旋转、后台返回不丢失，仅在接受后清理同一版本草稿；进程死亡后的草稿恢复尚未提供。键盘弹出时回复区保持可见，终端按键默认折叠，中断独立确认。

验收：点审批后必须给出「已送达 / 未送达 / 不确定」三态之一；切页不会把 A 的审批打到 B 上。

## 6. 终端页

职责：一个**真的能用**的 SSH 终端，与 Herdr 桥的健康状况无关。

- 顶部身份条：返回、主机名、`user@host:port`、连接灯、重连、溢出菜单（字号、输入模式、粘贴）。
- 终端网格：等宽字体、跟随 / 回到底部、长行横向滚动、可选择复制。
- 按键栏：默认两行，含 Ctrl 锁定、Esc、Tab、**Shift+Tab**、退格、方向键、^C/^D/^Z、PgUp/PgDn；长按可连发。
- 输入模式：行输入（回车提交）与直通（逐字送入，适合 vim / tmux）；直通模式下中文输入法组合态不会漏字。
- 首次连接必须人工确认指纹；指纹变化一律拒绝并给出下一步。
- 断线保留屏幕内容并显示错误分类与重连入口。

验收：`htop`、`vim`、`tmux` 可用；长行可横向查看；中文输入不丢字；字号可调且被记住。

## 7. 机器列表

职责：管理连接，并在一次点击内进入终端。

- 主按钮永远是「打开终端」；「连接会话」是 Herdr 桥的次要入口，桥坏了不影响终端。
- 卡片显示连接灯、`user@host:port`、状态文案、最后成功同步；失败时给一句指向下一步的提示，原始原因收进「详情」。
- 溢出菜单：编辑、移除（移除需确认）。连接详情可复制诊断信息。

验收：一眼看出哪台在线；连接失败文案能指向下一步。

## 8. 结构与任务

- 按 Herdr 的真实层级展示，不把桌面布局缩成手机上的迷你地图。
- agent pane 始终显示；空 shell 默认折叠可展开。
- 新建任务一次完成：选在线机器 → 新工作区或已有工作区 → agent 类型 / 名字 / 续接参数 → 启动。
- 启动 / 恢复到已有 pane 时只提供可保守确认的空 shell，排除当前占用；额外参数每行一个，保留空格。
- 恢复：记住每个 pane 上次的 agent，Herdr 或 App 重启后可向原 pane 重新启动并续接会话。
- 关闭工作区 / 标签页 / 分屏必须确认，不做批量关闭。
- 重命名覆盖 workspace / tab / pane / agent。worktree 只展示 Herdr 已有信息，不支持在手机上创建。

## 9. 设置

设置里只放**会改变行为**的选项。纯说明性内容合并成页脚一行小字，不单独占卡片。

| 分组 | 项 | 取值范围 | 默认 |
|---|---|---|---|
| 外观 | 语言 | 跟随系统 / 简体中文 / English | 跟随系统 |
| 外观 | 主题 | 跟随系统 / 浅色 / 深色 | 跟随系统 |
| 外观 | 动效 | 完整 / 减弱（取消位移与缩放，只留淡入淡出） | 完整 |
| 外观 | 密度 | 舒适 / 紧凑 | 舒适 |
| 终端 | 字号 | 9–22sp 步进 | 13sp |
| 终端 | 默认快照行数 | 400 / 1200 | 400 |
| 终端 | 按键栏 | 1 行 / 2 行 | 2 行 |
| 终端 | 长按连发 | 开 / 关 | 开 |
| 终端 | 输入模式 | 行输入 / 直通 | 行输入 |

- 「本机安全」只有一个动作：重置主机指纹，二次确认并说明后果（下次连接需重新确认）。
- 「关于与诊断」显示当前版本与「检查更新」；更新检查是 App 唯一的非 SSH 网络请求，用户手动触发，读取 GitHub Release。
- 语言切换：Android 13+ 用平台应用级语言，立即生效并跨进程保留；Android 12 及以下明确提示语言跟随系统，不做假开关。
- 状态词、时间描述、复数、无障碍描述、对话框与底部面板全部随语言变化；终端按键标签（Esc/Tab/Ctrl）属专业术语，保持英文。

**不可配置的安全红线**：首次连接必须人工确认指纹、指纹变化一律拒绝、后台不做任何自动审批、凭据不可导出。

## 10. 文案原则

- 说结果，不说实现：「前台 5 秒一次，离开即断开」，不写「基于轮询」。
- 失败必须给下一步：「主机指纹变了，可能是重装，也可能是有人在中间」+ 查看差异 / 信任新指纹。
- 不承诺没做到的事：没有通知就写没有通知；没有回执就不写回执。
- 危险动作的确认按钮写动词，不写「确定」。
